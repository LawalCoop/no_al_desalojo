# No al Desalojo — Lof Kinxikew · Lof Melo

Sitio estático de difusión de información de las comunidades Lof Kinxikew y Lof Melo.

## Estructura

```
index.html
assets/
  css/styles.css
  js/main.js
  img/hero.jpg       # foto de fondo del header
  img/favicon.svg
```

## Desarrollo

Abrí `index.html` directo en el navegador, o levantá un server simple:

```
python3 -m http.server 8000
```

y entrá a `http://localhost:8000`.
